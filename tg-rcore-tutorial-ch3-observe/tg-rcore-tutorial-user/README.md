# tg-rcore-tutorial-user (T2L21 subset)

This bundled user crate is the minimized workload set used by `joshua912815-tg-rcore-tutorial-t2l21`.

Included binaries:

- `00hello_world`
- `01store_fault`
- `11sleep`
- `ch3_trace`
- `t21_ch3_normal`
- `t21_ch3_breakpoint`
- `t21_ch3_crash`

The package intentionally keeps only the `T2L21` case groups required by the Chapter 3 observability experiment.
